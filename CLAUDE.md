## What This Is

Spotfile is a native desktop application built with [Wails](https://wails.io/) v2 — Go on the backend, Svelte/TypeScript on the frontend, compiled into a single native binary with an embedded webview.

## Commands

### Development
```bash
wails dev          # Start full dev mode (Go + frontend with hot reload)
```

### Build
```bash
wails build        # Compile production binary to build/bin/
```

### Frontend only (from project root, not frontend/)
```bash
cd frontend && npm install   # Install dependencies
npm run check                # svelte-check type checking
npm run build                # Build frontend assets to frontend/dist/
```

### Go
```bash
go build ./...     # Compile Go code
go vet ./...       # Run Go vet
```

## Architecture

The Wails framework bridges Go and the web frontend:

- **`main.go`** — Entry point. Initializes the Wails app, embeds `frontend/dist` into the binary, configures the window, and binds the `App` struct so its exported methods become callable from JavaScript.
- **`app.go`** — The `App` struct. Any exported method here is automatically available in the frontend via generated bindings at `frontend/wailsjs/go/main/App.js`. Add new backend capabilities here.
- **`frontend/src/App.svelte`** — Main UI component. Calls Go methods by importing from `../wailsjs/go/main/App.js`.
- **`frontend/wailsjs/`** — Auto-generated by Wails. Do not edit manually; regenerated on `wails dev`/`wails build`.

### Frontend–Backend Communication Pattern

1. Add an exported method to `App` in `app.go`
2. Run `wails dev` or `wails build` — bindings are auto-generated into `frontend/wailsjs/`
3. Import and call from Svelte: `import { MethodName } from '../wailsjs/go/main/App'`
